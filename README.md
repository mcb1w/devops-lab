# DevOps Lab

Учебный проект на Go для практики основ разработки и DevOps. Сейчас это небольшой HTTP-сервер с проверками состояния, ограничением HTTP-методов, автоматическими тестами и корректным завершением работы.

## Запуск

Нужен Go. Версия Go для проекта указана в `go.mod`.

Запусти сервер из корневой папки проекта:

```bash
go run .
```

Сервер слушает порт `8000`:

- Главная страница: <http://localhost:8000/>
- Проверка состояния: <http://localhost:8000/health>

## Маршруты

| Метод | Путь | Результат |
|---|---|---|
| `GET` | `/` | Приветствие `Hello from devops-lab!` |
| `GET` | `/health` | JSON `{"status":"ok"}` |
| `GET` | неизвестный путь | `404 Not Found` |
| Другой метод | `/` или `/health` | `405 Method Not Allowed`, заголовок `Allow: GET` |

Примеры запросов:

```bash
curl -i http://localhost:8000/
curl -i http://localhost:8000/health
curl -i -X POST http://localhost:8000/health
```

## Тесты

Запусти автоматические проверки командой:

```bash
go test
```

Тесты проверяют ответы главной страницы и `/health`, неизвестный путь, а также отказ для `POST` на существующие маршруты.

## Остановка

Нажми `Ctrl+C` в окне, где запущен сервер. Он перестанет принимать новые подключения и даст текущим запросам завершиться. На штатное завершение отводится до 5 секунд.
